🏎️ BOX BOX — Formula 1 Race Control

Your personal Formula 1 pit wall.

BOX BOX is a Formula 1-inspired race-control dashboard designed to bring the experience of a professional F1 pit wall to your screen.

Built with a clean interface, racing-red accents, white backgrounds and light-grey surfaces, BOX BOX brings essential motorsport information together in one place.

📡 Data & Accuracy

BOX BOX is designed to support Formula 1 session data and telemetry integrations.

Important distinctions:

- Actual live data depends on the availability of a supported data source.
- Simulated telemetry should not be confused with official race telemetry.
- Some dashboard panels may use sample or generated information when live data is unavailable.
- Data availability may vary depending on the session and API access.

The objective is to make the dashboard increasingly accurate and useful during actual F1 sessions.
